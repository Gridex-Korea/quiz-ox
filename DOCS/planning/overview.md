# 개요와 범위

## 배경

손을 들거나 몸으로 이동하는 전통적 OX 퀴즈는 인원이 많아지면 정답자 집계가 느리고 부정확하며, 누가 몇 번 틀렸는지 사회자가 기억할 수 없다. 참가자 각자의 스마트폰을 입력 장치로 쓰고 대형 스크린을 무대로 삼으면 집계는 즉시 끝나고, 아바타가 O·X 구역으로 뛰어가는 연출로 현장 분위기도 살릴 수 있다. 사회자 한 명이 노트북으로 전체 진행을 통제할 수 있어야 한다.

## 목표

- 참가자가 QR 코드 스캔 후 **30초 안에** 전화번호·이름 입력을 마치고 로비에 나타난다.
- 문제당 O/X 집계가 제한시간 종료 후 **1초 안에** 대형 스크린에 표시된다.
- 아바타 이동이 참가자 탭 후 **0.5초 안에** 스크린에 반영된다(네트워크 정상 기준).
- 오답 1회 → 대기실(관전), 패자부활전 정답 → 무대 복귀, 오답 누적 2회 → 퇴장 규칙이 사람 손을 거치지 않고 자동으로 적용된다.
- 중반에 1회 **패자부활전**을 버튼 하나로 열 수 있고, 콘솔이 예정 시점을 알려준다. 그동안 무대 생존자는 관전한다.
- 초반 문제는 아바타 이동을 실시간으로 보여 분위기를 띄우고, 후반 문제부터는 마감 뒤 일제히 공개해 눈치 답변을 막는다.
- 사회자가 실수했을 때(잘못된 정답 공개, 조기 종료) **직전 라운드를 되돌릴 수 있다**.
- 폰 브라우저가 잠기거나 새로고침되어도 같은 전화번호로 **자기 자리에 복귀**할 수 있다.

## 범위 밖 (Non-goals)

- 게임 시작 후 신규 입장. 사회자 본인이 "당연히 중간에 들어오는 건 없다"고 확정했다.
- 회원가입·로그인·비밀번호. 전화번호와 이름만으로 식별한다([[ADR-0003-phone-identity]]).
- 여러 행사를 동시에 운영하는 멀티 테넌시. 한 번에 한 게임(방 1개)만 돌아가면 된다. 방 코드는 두지만 동시 운영은 보장하지 않는다.
- 4지선다, 주관식, 순위 점수제. 이번 범위는 O/X 생존 게임만이다.
- 참가자 간 채팅, 이모지 반응. 연출은 아바타 이동과 이름 표시로 충분하다.
- 네이티브 앱. 모바일 웹 브라우저(iOS Safari, Android Chrome)만 지원한다.
- 패자부활전 이외의 복귀 경로(추첨 부활, 시간제 자동 부활 등). 예외적인 복귀는 사회자의 수동 복구 기능으로 갈음한다.
- 앱 안에서의 최종 결승(추가 문제 채점, 가위바위보). 최종 생존자를 무대로 불러 오프라인으로 진행하고, 앱은 생존자 명단과 우승자 표시만 한다.
- 참가자용 LAN 모드. 행사장에 인터넷이 없고 핫스팟 하나에 폰 50대를 붙일 수 없으므로, 참가자는 반드시 자기 이동통신 데이터로 클라우드 서버에 접속한다.

## 이해관계자

| 역할 | 담당 | 비고 |
|---|---|---|
| 사회자(진행·운영) | 사용자 본인 | 문제 준비, 진행 콘솔 조작, 경품 지급 |
| 참가자 | 행사 참석자 | 본인 스마트폰 사용, 사전 안내 없음 → 첫 화면이 곧 사용법 |
| 스크린 운영 | 사회자 또는 보조 1명 | 빔프로젝터/TV에 브라우저 전체화면으로 스크린 화면을 띄움 |
| 개발 | 사용자 + Claude Code | 이 문서의 로드맵을 따름 |

## 성공 기준

- 리허설에서 실제 폰 10대 이상으로 일반 5문제 + 패자부활전 1회를 끝까지 진행하고, 대기실 이동·복귀·퇴장이 규칙대로 일어난다.
- 부하 테스트에서 가상 참가자 100명이 동시에 답해도 집계와 아바타 반영 지연이 목표치 안에 들어온다.
- 본행사에서 사회자가 개발자 도움 없이 콘솔만으로 처음부터 끝까지 진행한다.

## 전제

> [!note] 전제
> - 참가자는 약 50명이다(사회자 확인). 설계 상한은 여유를 두어 100명으로 잡는다. 이 규모면 서버 1대와 DOM 렌더링으로 충분하다.
> - 행사장에 WiFi·유선 인터넷이 없다. 사회자 노트북은 휴대폰 핫스팟으로 인터넷에 연결하고, 참가자는 QR 코드로 접속해 자기 이동통신 데이터를 쓴다. 핫스팟 하나에 폰 50대를 붙이는 것은 기기 제한(보통 10대 내외) 때문에 불가능하므로 참가자용 LAN 모드는 계획에서 뺀다.
> - 사회자는 노트북 1대(콘솔)와 별도 출력 장치 1대(스크린)를 쓴다. 노트북 하나에서 창을 둘로 나눠 쓰는 것도 가능하다.
> - 문제는 사회자가 사전에 준비하며, 행사 중 즉석 출제는 예외적으로만 한다.
