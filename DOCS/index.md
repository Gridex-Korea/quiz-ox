# OX 퀴즈 라이브

행사장에서 사회자가 진행하는 OX 퀴즈를 **참가자 스마트폰 + 대형 스크린**으로 옮긴 실시간 웹 게임이다. 참가자는 QR 코드로 접속해 전화번호와 이름(별명)을 입력하고 입장한다. 문제가 나오면 각자 폰에서 O 또는 X를 누르고, 대형 스크린에서는 참가자의 미니미(아바타)가 O 구역과 X 구역으로 뛰어가는 모습이 보인다. 초반 문제에서는 실시간으로 보이고, 후반 문제부터는 마감 뒤에 일제히 공개된다. 시간이 끝나면 양쪽 인원이 공개되고 정답이 발표된다. 틀리면 **대기실**로 이동해 관전만 하고(경고 1회), 사회자가 여는 **패자부활전**에서 맞히면 무대로 돌아온다. 오답이 누적 두 번이면 **완전히 퇴장**한다. 게임이 시작된 뒤에는 새로 들어올 수 없다.

## 현재 상태

> [!note] 지금 어디까지 왔나
> 기획 확정 뒤 마일스톤 1~3(게임 루프, 무대 연출, 운영 기능)을 구현했고 브라우저 실동작과 가상 참가자 100명 부하 테스트를 통과했다(2026-09-16). 코드는 저장소 루트의 `shared/`·`server/`·`web/`, 실행법은 [[runbook]] 하단. 마일스톤 4는 Docker 이미지·배포 스크립트까지 준비되었고 **실제 Cloud Run 배포는 사회자 승인과 GCP 프로젝트 정보가 필요**하다. 남은 결정: 행사 날짜·장소, 전화번호 고지 문구.
